**Aidyn ReChronicled 1.0.1.** A bug fix for 1.0.0, through **Updates** on the title menu. There's no new download: a new install takes 1.0.0 and updates from there.

## Fixed

- **"ACTION EDITION" at the top right while fast-forward is on** (#76). The fast-forward marker showed the title card's ACTION EDITION line instead of its two chevrons, in every version of the game; it only showed with fast-forward on, so clicking the left stick (L3) again turned it off. The chevrons are back.
