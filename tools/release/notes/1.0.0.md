**Aidyn ReChronicled 1.0.0.** The first full release with in-game updates: from here on, **Updates** on the title menu
brings each new release in, downloading only what changed. Everything since 0.9.1 is below; 0.9.2 was the test build.

## What's new since 0.9.1

- **In-game updates.** At each start the game looks on GitHub for a newer release, and a line at the top of the title
  screen says when one is out. **Updates** on the title menu shows what's new; **Update** downloads only the files
  that changed (each one checked, and the list of them signed, so nothing else can be slipped in), and **Restart now**
  puts them in, or the next start does. **Undo the last update** goes back. Saves, settings and ROMs aren't touched.
  **Check at start** turns the looking off; **Test builds too** also offers test builds. Linux (Steam Deck and Bazzite
  Game Mode included) and Windows 10 / 11; under Wine or Proton it opens the release page instead.
- **Frame rate on the Display page:** 60, 90, 100, 120, 144, 175, 240 or Unlimited, applied straight away and
  remembered.
- **Above 60 fps on Steam Deck / Bazzite Game Mode and on Linux desktops.** Under Game Mode (gamescope) and through
  XWayland the game read every screen as 60 Hz and held itself to that; it now uses the frame rate you set, and on a
  Linux desktop it opens its window through Wayland, which gives the real rate.
- **Anti-aliasing and Supersampling are separate rows on the Display page.** Anti-aliasing is MSAA alone (Off, 2x, 4x,
  8x); Supersampling is its own row (Off, 2x).
- **Supersampling is off by default.** On handhelds such as the ROG Xbox Ally X, 2x supersampling is more than the
  graphics chip can draw at 120 frames a second, and the game then drops back to its own 60; MSAA 4x alone holds 120.
  A new install starts with it off; **an existing install keeps its setting**, so set Supersampling to Off on the
  Display page if you're held at 60.
- **LB quicksaves, View shows or hides the controls card** (the other way round before). The card, the Help book and
  the keyboard (Q quicksaves, J the card) follow.
- **Camera sensitivity** on the ReChronicled page, walking and battle each its own: how fast the right stick turns the
  camera, 0.5x to 2x walking (1x by default) and 0.25x to 2x in a fight (0.5x by default).
- **The party row leaves no sliver** at the bottom of the screen once it has slid away.
- **The controller you're using is the one the game reads.** It used to read only the first controller in the
  system's list; on the ROG Xbox Ally X under Steam Input that wasn't the one in your hands. Now whichever controller
  you press or move is followed.
- **The title card is centred** (the game had it 12 units left of the middle).
- **Display on the title menu:** the Display settings (widescreen, textures, VSync, window, frame rate, FPS counter,
  HUD at the screen edges, draw distance, anti-aliasing, supersampling) can now be set before starting a game, not
  only from the pause menu.
- **Books in the world** (Becan's Journal and the like) no longer say B closes them: their hints read Choose A (the list;
  Leave the Journal closes it) and Return A (an entry's page). The map's Journal and the Help book still close with B.
- **The title menu hides under its panels** (Controls, Achievements, Updates); its box and last entries showed below
  them.
- **The game's name on its title is now "Aidyn ReChronicled: The First Mage"**: a new logo (AIDYN, RECHRONICLED, THE FIRST
  MAGE) on the title screen, the Steam art, the manual's cover and the GitHub page.
- **The Steam library art** has the woman's sword back as in the original cover (a long sword in its black scabbard
  across her hips; the repainted art had lost the scabbard). Handhelds pick it up with `steam_shortcut.py`.
- The title screen shows a test build's version properly ("v0.9.1 patch2", not "v0.9.1      1").
- The log (`logs/last-run.log`) has a `Display:` line with the refresh rate the game read, for problem reports.
