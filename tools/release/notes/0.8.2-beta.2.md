## What to try in this test build (0.8.2-beta.2)

This is a patch over 0.8.1 (README.txt in the download says how to put it over), and it replaces beta.1: everything in
beta.1 (keyboard and mouse play, the Controls page, "Continue" in conversations, your keys on the controls card, the
Help book's ReChronicled topic) is in it, plus the fix below. The key and mouse pictures are still not in; prompts show
your keys as text. Anything odd, or anything you'd change: the Problem report form
(https://github.com/spitzdano/AidynReChronicled/issues/new?template=problem-report.yml; say it's the test build).

- **A crash after changing the draw distance is fixed (#27).** In a forest with a high draw distance (the first one,
  after the conversation at Kendall's Hat), changing the draw distance in the pause menu could end the game: the
  game counts how many trees use each picture in a number that only goes to 127, and a forest has more, so a picture
  was freed while trees were still drawn with it. The count now goes past 127 safely. To check: Display page (pause
  menu, ReChronicled), change the Draw distance a few times back and forth, walk around, and change it again; the
  game should keep going. If it still stops, send the problem report (the form above).
