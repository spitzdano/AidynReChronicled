## What's new since 0.2.0

- **Saves changed outside the game are picked up**: if `aidyn.mpk` is replaced while the game runs (saves synced
  in from another device, a backup put back), the next save or load uses the new file instead of writing the
  game's older copy over it. The game's copy goes to `backups/` first. For playing on two machines: sleep the game
  on one, play and save on the other, and once the newer file has arrived, the first one's save and load screens
  show it (load it to continue from there).
