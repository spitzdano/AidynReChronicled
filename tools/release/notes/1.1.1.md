**Aidyn ReChronicled 1.1.1.** Through **Updates** on the title menu on Linux and Windows. macOS has a new download for this version: a new Mac install, or an update from the release page, takes it from here.

## Fixed

- **macOS: the pause menu and quicksave no longer crash the game.** Both take a picture of the screen for the save, and the Mac's graphics layer had no way to copy it out. The game closed the moment Enter or the quicksave key was pressed.

## Changed

- **Fast-forward is a switch on the keyboard too.** Press Tab to turn it on and again to turn it off, the way the left stick click works on a controller, instead of holding the key down.
- **macOS keeps a log.** Started from Finder or the Dock, the game writes `logs/last-run.log` in its data folder, and a problem report holds it. A crash on a Mac now names where it happened in a form that can be looked up.
