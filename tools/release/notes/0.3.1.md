## What's new since 0.3.0

- **Text spacing fixed with any HD menu pack**: the HD letters and Xbox button icons now come with the release
  (`rechronicled-text`, drawn from fonts) and take priority over the HD menu pack's, so text is spaced right whatever
  version of `hd-ui` is installed, or none. An older `hd-ui` used to give squeezed or gappy text ("LOADGAME",
  "O PTIONS"). Existing settings files get the new pack added once.
