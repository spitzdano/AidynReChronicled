## What's new since 0.5.1

- **Windows**: a native Windows build (Windows 10 or 11, 64-bit), with every feature of the Linux one: unpack
  `AidynReChronicled-0.6.0-windows-x86_64.zip` anywhere and run `AidynReChronicled.exe`. Nothing to install (the
  Visual C++ runtime is in the folder). **Add to Steam.bat** adds it to Steam with its icon and library art. Saves,
  settings and problem reports are in `%APPDATA%\AidynReChronicled`, and saves move between the Linux and Windows
  builds as they are.
- **The ROMs folder**: both downloads have a `ROMs` folder. Put your 1.0 ROM in it, and the same ROM with Aidyn Patch or
  Aidyn Plus applied if you have them, under any names (`.z64`, `.n64` or `.v64`): at the next start the game finds
  each by its contents, keeps a copy and lists it on the title screen, so the patched versions no longer need a launch
  option or a menu entry to be added. On Linux, `install.sh` copies them into `~/Games/AidynReChronicled/ROMs` and keeps
  that folder through updates. Without any ROM there, the first start asks for one as before.
- **Always a version that can start**: if the version you played last has no ROM (only Aidyn Plus, say), the game plays
  one that has, and the title screen lights that one, instead of asking for a ROM you may not have.
- **Faster start**: the texture packs now come as three `.rtz` files instead of about 40,000 small ones, so the game
  reaches its first frame in under a second on Linux and about two on Windows, and the download unpacks faster.
- **Window on the Display page**: Windowed or Borderless (full screen), switched at once and remembered; F11 and
  Alt+Enter do the same and are now remembered too.
- **The inventory page's painting everywhere**: without the HD menu pack (which no release has), a band of the old
  page showed behind HitPoints, Level and Gold. The painted page now shows whole.
- **Start-up timings** in `logs/last-run.log`, to see where a slow start goes.

Already installed on Linux? Unpack this release and run `bash install.sh` again: it replaces the game and keeps your
saves, settings and ROMs. On Windows, unpack it over the old folder or into a new one: your saves and settings are in
`%APPDATA%`, not in the game's folder.
