## What's new since 0.8.0

- **Better crash reports, for the crash after the first forest (#27).** That crash is still not understood, so this
  release makes it easier to catch: on Windows a crash's problem report now holds a minidump (`logs/crash.dmp`, every
  thread's stack at the moment of the crash), so a report says where the game was, not just that it stopped. A game
  that freezes, or is closed by force, makes a report the next time it starts, with the game's last known state. If the
  game crashes, send the newest `report-....zip` from the `reports` folder (Windows: `%APPDATA%\AidynReChronicled\reports`)
  through the Problem report form on GitHub.
- **Storm lightning no longer flashes three times as often.** The game checks for a lightning flash every 20th frame,
  once a second on the N64 and three times a second at 60 frames a second. It is back to about once a second.
- **Fewer pops in the music.** The game now keeps a little more sound ready ahead of time, so a slow moment (a map
  loading at a long draw distance) no longer leaves a gap that played as a pop or a crackle. The log notes when one
  still happens ("Sound: ran dry").
- **A save made by another version is not loaded by mistake**: Continue and Quick Load say to switch versions on the
  title screen instead of loading a save from Aidyn Patch into the original (or the other way round).
- **Ground at the sides of a widescreen picture** is drawn, so the edges no longer show bare spots.
- **Combat**: spell and skill descriptions show the stamina they cost against what is left, and a blue zZ on a
  portrait marks a fighter with no stamina left.
- **The title menu** has a new panel in the style of the turn order bar.
- **The manual** says stamina is never spent past what is left, and that vigour is the level's bonus points.

Already installed on Linux? Unpack this release and run `bash install.sh` again: it replaces the game and keeps your
saves, settings and ROMs. On Windows, unpack it over the old folder or into a new one: your saves and settings are in
`%APPDATA%`, not in the game's folder.
