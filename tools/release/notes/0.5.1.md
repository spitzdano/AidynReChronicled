## What's new since 0.5.0

- **Steam library art**: the installer's Steam step now gives the game its own artwork in your library: the box
  painting, without its title and redrawn for each of Steam's shapes, with the ReChronicled title card on the library
  capsule and the wide capsule, the painting as the page banner and the title card as its logo. If you add the game
  by hand, the pictures are in `~/Games/AidynReChronicled/steam-art/` (the README says where each goes).
- **A new icon**: the swordsman from the box painting, in the app menu and on the Steam shortcut, in place of the
  illuminated A.
- **The README in the download** has the features list and a word on where the project stands: a hobby project, a work
  in progress, not yet played very far. Playtests and problem reports from further along are very welcome.
- **The project is public**: the code at https://github.com/spitzdano/AidynReChronicled (with screenshots and the
  Problem report form for issues) and the tools it's built with at https://github.com/spitzdano/n64-recomp-toolkit.

Already installed? Unpack this release and run `bash install.sh` again: it replaces the game and keeps your saves and
settings, and its Steam step updates the shortcut with the new art (Steam closes for a moment).
