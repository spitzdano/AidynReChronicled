**Aidyn ReChronicled 1.1.3.** Through **Updates** on the title menu on Linux and Windows, or as a full download for Linux, Windows and macOS (Apple Silicon): a new install can start here.

## Fixed

- **The Healer, Alchemist and Mechanic menus can be chosen from.** A on one of those skills on the Character page opened its menu (Lay On Hands, Heal With Herbs, Restore; the potions to brew), but the D-pad and the left stick kept moving the skills list under it, so nothing in the menu could be picked. A pop-up over the Inventory or Spells page now has the keys too.
- **The game's timers can't stop firing.** A timer stopped late, after its memory was reused, could leave the runtime's timer list out of order, and later timers never fired (a pause menu hung in a sleep, seen in another port; not yet reported in this game).

## Changed

- **With the keyboard, the pause pages' arrow shows one key at each end.** The left end shows the camera-left key and the right end the camera-right key, next to the arrow, where both were shown at both ends.
- **The Lists prompt's two keys no longer run into the next list's name** on the Inventory, Character and Spells pages.
