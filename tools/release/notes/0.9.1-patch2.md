## What's in this patch

Replaces 0.9.1-patch1 (everything it had is here too). Goes over an installed 0.9.1.

- **Frame rate on the Display page:** 60, 90, 100, 120, 144, 175, 240 or Unlimited, applied straight away and
  remembered.
- **Above 60 fps on Steam Deck / Bazzite Game Mode and on Linux desktops.** The game never showed more frames than the
  screen's refresh rate, and under Game Mode (gamescope) and through XWayland it read every screen as 60 Hz, so it was
  held to 60 on 100 and 120 Hz screens. Under Game Mode it now uses the frame rate you set; on a Linux desktop it opens
  its window through Wayland, which gives the real rate.
- **Anti-aliasing and Supersampling are separate rows on the Display page.** Anti-aliasing is MSAA alone (Off, 2x, 4x,
  8x); Supersampling is its own row (Off, 2x). Before, one Anti-aliasing row's Medium and High levels turned on both.
- **Supersampling is off by default.** On handhelds such as the ROG Xbox Ally X, 2x supersampling is more than the
  graphics chip can draw at 120 frames a second, and when it falls behind the game drops back to its own 60. MSAA 4x
  alone held a steady 120 there. A new install starts with it off; **an existing install keeps its setting**, so set
  Supersampling to Off on the Display page if you're held at 60.
- The title screen shows a patch's version properly ("v0.9.1 patch2"; patch1 showed "v0.9.1 1").
- The log (`logs/last-run.log`) has a `Display:` line with the refresh rate the game read, for problem reports.

**What to try:** on a screen faster than 60 Hz, set Frame rate to its rate (or Unlimited), turn on the FPS counter
(also on the Display page), and if it stays at 60, set Supersampling to Off.
