Put your Aidyn Chronicles ROMs in this folder:

  - the North American 1.0 cartridge (.z64, .n64 or .v64), and if you have them,
  - the same ROM with Aidyn Patch applied,
  - the same ROM with Aidyn Plus applied.

Any file names will do: the game recognises each one by its contents when it
starts, keeps a copy, and lists the versions it found on the title screen
(X and Y switch between them). Nothing from the game comes with this download.
